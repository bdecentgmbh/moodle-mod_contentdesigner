# Image element — Teacher guide

The Image element shows one image, or several images as a slideshow with indicators and arrows.

## Settings

- **Images**: upload one or more images. Several images are shown as a slideshow.
- **Caption**: a caption below each image.
- **Show in lightbox**: learners click an image to see it enlarged.

The general settings of elements (description, spacing, backgrounds, animation, responsive visibility) apply as
for every element.
